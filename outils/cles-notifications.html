Clés des rappels

Cette page crée la paire de clés qui permet d’envoyer les rappels de séance. Tout se passe dans ton navigateur : rien n’est envoyé sur Internet.

À mettre dans js/config.js, champ vapidPublicKey. Elle peut être partagée sans risque.

Secrète : colle-la uniquement dans le secret GitHub VAPID_PRIVATE_KEY. Ne l’envoie à personne, pas même par message.

  1. Sur GitHub : Settings → Secrets and variables → Actions → New repository secret, nom VAPID_PRIVATE_KEY, colle la clé privée.
  2. Mets la clé publique dans js/config.js (ou envoie-la à la personne qui gère le code).
  3. Ferme cette page : les clés ne sont enregistrées nulle part.
